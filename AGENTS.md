# AGENTS.md

This repo is one README: a student's guide to AI coding agents, written in Ario's voice.

- Write like you speak. Short, direct, opinionated. No em dashes.
- Every price, quota, or offer links to a source. Prefer the official page; practitioner reports are fine if dated and labeled.
- When facts change, update the "Last reviewed" date and fix every place the fact appears (quick reference, tool section, My Workflow, Sources).
- Cut before adding. If a sentence repeats a table, delete the sentence.
- Check that headings still match the anchor links near the top after renaming any section.
